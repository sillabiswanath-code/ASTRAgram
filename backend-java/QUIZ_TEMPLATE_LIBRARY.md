# Universal Quiz Template Library

## Purpose

This template library is designed for generating 1-mark questions on any topic, subject, lesson, chapter, video, podcast, or educational content.

The templates support:

* Any subject
* Any grade level
* Any language
* Easy, Medium, and Hard difficulty levels
* Knowledge, understanding, application, and reasoning-based assessment

---

# Difficulty Framework

## Easy

### Goal

Direct recall and recognition.

### Skills Tested

* Definition recall
* Fact identification
* Example recognition
* Vocabulary understanding

### Recommended Formats

* Single Correct MCQ
* Fill in the Blank
* True/False
* Identify Example
* Match the Following

---

## Medium

### Goal

Concept understanding and application.

### Skills Tested

* Application
* Comparison
* Classification
* Cause and Effect
* Scenario Analysis

### Recommended Formats

* Multiple Correct Answers
* Scenario-Based Questions
* Best Explanation
* Compare Concepts
* Cause and Effect

---

## Hard

### Goal

Reasoning and misconception detection.

### Skills Tested

* Critical Thinking
* Analysis
* Exception Finding
* Conceptual Understanding
* Error Detection

### Recommended Formats

* Assertion–Reason
* Indirect Questions
* Find the Mistake
* Choose the Most Accurate Statement
* Misconception-Based Questions

# Validation Rules

Every generated question must satisfy:

1. Tests exactly one learning objective.
2. Uses terminology from the lesson.
3. Avoids ambiguity.
4. Has plausible distractors.
5. Is answerable using lesson content.
6. Maintains consistent difficulty.
7. Avoids grammatical clues.
8. Avoids answer-pattern bias.
9. Uses realistic examples.
10. Maintains conceptual accuracy.

---

# Advanced Generation Rules

When generating questions:

* Topic must remain central to the question.
* Distractors should be believable.
* Hard questions should test reasoning, not obscure facts.
* Scenario questions should mirror real-life situations.
* Multiple-correct questions must clearly specify the number of correct answers.
* Fill-in-the-blank options must fit grammatically.
* Match-the-following pairs must be unique.
* Avoid repeated wording patterns.
* Avoid giving away the answer through option length.
* Ensure answer distribution is balanced across A, B, C, and D.
